# Razor
This project represents the completed EventEase application developed across multiple activities using Microsoft Copilot. Copilot assisted in generating the foundational Event Card component with two‑way data binding, enabling dynamic updates to event details. It also helped create and refine routing between pages, including event lists, event details, registration, and attendance tracking.

During debugging, Copilot provided suggestions to resolve routing errors, null reference issues, and input validation problems, improving overall stability. Copilot also supported performance optimization by recommending guard clauses, validation attributes, and cleaner component structures.

Advanced features such as a Registration Form with validation, a session‑based state management service, and an Attendance Tracker were implemented with Copilot’s guidance. These additions enhance usability and demonstrate full-stack Blazor functionality.
